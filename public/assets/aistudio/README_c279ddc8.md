# Jackson Hong — Student Portfolio

A responsive, single-page English portfolio for Jackson Hong (Chadwick International School, Class of 2029).

## Files
- `index.html` — page content and structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and footer year

## Preview locally
Open `index.html` in a browser. An internet connection is used only for the Google Fonts loaded in the page; the site otherwise runs as static files.

## Publish publicly
Recommended simple hosting options:
1. **Netlify** — create a new site by uploading this folder (or connect a Git repository).
2. **GitHub Pages** — create a repository, upload the three site files, then enable Pages in repository settings.
3. **Vercel** — import the repository and deploy as a static site.

A custom domain can be connected through the hosting provider.

## Before publishing — important checklist
- Replace the blank `mailto:` link in `index.html` with an email address intended for public contact, or remove the contact button.
- Confirm the exact wording and event scope of the recent golf result (currently marked with an editorial note).
- Confirm the official name/category of the 2024 John Locke recognition.
- Confirm the precise school-record wording and whether the 50m breaststroke record was held through June 2026.
- Add approved photographs (portrait, golf, swimming, writing, guitar) if desired. The current hero and sport visuals are CSS artwork, not photographs.
- Obtain permission before publishing identifiable images, school marks, team names, certificates, or other students.
- Since this is a public website for a minor, consider using a dedicated contact email and avoid publishing phone number, home address, exact schedules, or other sensitive details.

## Editing
Search the HTML for the relevant section heading and update the copy directly. Keep claims precise and evidence-backed; add certificate images or official result links only when they are appropriate for public sharing.
